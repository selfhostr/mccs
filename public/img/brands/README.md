# Logos de marque

Les logos Android, Apple, Gmail, Samsung et Thunderbird (et les pictogrammes iOS/macOS) proviennent de
[Simple Icons](https://simpleicons.org), publiés sous licence CC0 1.0. Ils sont intégrés en SVG
dans `public/js/app.js` (objet `ICONS`).

Les logos Windows et Outlook sont des dessins simplifiés propres à ce projet (Microsoft n'est pas dans Simple Icons).

Tous les noms et logos de marque appartiennent à leurs propriétaires respectifs ; ils servent uniquement à
identifier les produits concernés.
